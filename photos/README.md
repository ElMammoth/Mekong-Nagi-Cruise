# Photos

Put original photos here, named exactly as the slot's `file` in `src/content/photos.ts`
(for example `nagi-of-mekong-boat-at-the-pier.jpg`). JPG, PNG, WebP, AVIF or TIFF, at least
1920 px wide when possible.

`npm run dev` and `npm run build` resize them automatically into `public/images/`.
The shot list is in `docs/06-shot-list.md`.
